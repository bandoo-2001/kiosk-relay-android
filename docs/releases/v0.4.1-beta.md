# KioskRelay v0.4.1 Beta

Android 11 TV 开机启动兼容更新。

## 更新内容

- Android 10 及以上在用户授予“显示在其他应用上层”权限后，收到开机广播时尝试直接打开应用；应用不绘制悬浮窗。
- 首次配置和运行设置增加启动授权入口、授权状态以及系统设置不可用提示。
- 未授权时使用恢复通知；已授权时也保留通知以应对厂商静默拦截，应用进入前台后移除。
- 补齐六种界面语言的启动授权提示，增加 Android 11 启动策略回归测试。
- 包含上一版本之后的 TV 首次配置和焦点测试改进，以及混淆优化的 Beta 构建配置。

## 安装与配置

最低支持 Android 7.0（API 24），本次 APK 版本为 `0.4.1-beta`，版本码为 `401`。

1. 安装 APK，手动打开应用并完成首次配置。
2. 开启“开机启动”，点击“授权开机启动”。
3. 在系统设置中允许本应用“显示在其他应用上层”，返回应用并保存。
4. 如果电视另有自启动或后台运行管理，也需允许本应用。
5. 分别验证系统重启、断电重启和待机唤醒；待机唤醒不一定发送开机广播。

APK 使用项目现有 Beta 配置及本机 Debug 密钥签名，供测试使用。如已安装版本签名不同，无法直接覆盖安装；请先导出配置，勿为升级直接删除数据。

## 验证与限制

- 62 个 JVM 单元测试通过；Android Lint 0 错误、53 个警告；Beta 构建与 APK 签名验证通过。
- 海信 55E3NH Pro 尚未进行真机重启验收，Android 11 TV 运行测试未执行。
- 若电视固件禁止授权、开机广播或后台启动，普通 APK 不能保证无人值守自动进入大屏，需厂商启动配置支持。
- 本版为 Beta，既有版本的其他运行验证边界见 README 和项目测试报告。

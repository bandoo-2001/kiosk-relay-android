# v0.4.4-beta

- 网页展示和预览窗口顶部固定显示系统 WebView 提供程序、版本和 Chromium 主版本。
- 版本条使用原生界面，网页滚动、加载提示和错误页面不会覆盖它。
- 未识别出提供程序版本或 Chromium 版本时，直接弹出原生提醒，遥控确认或返回可以关闭；顶部检测结果保留。
- 保留已有的旧内核前置提醒、继续加载选项和 30 秒超时处理。

本版本没有替换或内置浏览器内核。电视现场兼容问题仍需通过顶部版本信息及错误提示定位。

验证：63 项 JVM 测试、29 项 Android 11 TV 仪器测试通过；Lint 0 错误、53 项警告。Beta 覆盖安装及冷启动实测顶部版本条，目标网页 Token 页正常显示。未知版本使用模拟报告验证弹窗和遥控确认，尚无海信真机现场结果。

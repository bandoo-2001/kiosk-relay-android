# v0.4.2-beta

完善电视遥控交互：

- 修复开机延时滑条吞掉上下键导致无法离开的问题；左右调整 5 秒，上下切换控件。
- 设置栏目按实际横纵布局导航，可进入内容并回到当前栏目或保存。
- 开关整行只保留一个焦点，按钮和颜色选项增加焦点边框。
- 首次配置自动聚焦并重置滚动位置，支持返回上一步。
- 管理员验证、确认弹窗、网页预览、诊断页和错误重试提供明确焦点与返回路径。
- 网页展示将焦点交给 WebView，并在重试完成或关闭验证弹窗后恢复。

操作说明见 [TV-REMOTE.md](../TV-REMOTE.md)。

验证：62 项 JVM 单元测试、22 项 Android 11 TV 仪器测试通过；Lint 0 错误、53 项警告。Beta 包安装成功，ADB 实际方向键验证了设置栏目、滑条调整和退出到保存、管理入口、诊断滚动与返回。

本版本使用 Android 11 TV 模拟器验证。海信 55E3NH Pro 仍需真机验收；网页自身须支持键盘焦点，系统输入法、授权页、文件选择器的交互由电视系统提供。Beta 包使用本地调试签名，不代表正式生产签名版本。

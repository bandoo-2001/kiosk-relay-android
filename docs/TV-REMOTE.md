# 电视遥控操作

适用于应用原生界面；已使用 Android 11 TV 模拟器验证，海信 55E3NH Pro 尚需真机验收。

- 方向键移动焦点，边框表示当前操作对象；确认键执行按钮或切换开关。
- 首次配置每一步自动聚焦首个选项；返回键回到上一步，底部“上一步 / 下一步”可用左右键选择。
- 横屏设置侧栏上下切换栏目，右键或确认进入内容；窄屏顶部栏目左右切换，下键或确认进入内容。
- 输入框左右键保留光标编辑，上下键移到前后控件。确认打开系统输入法，输入法显示时按系统规则操作；返回先收起输入法。
- 开机延时滑条：左减 5 秒，右加 5 秒，范围 0–60 秒；上下键移到前后控件，无需拖动。设置页滑条下键到保存，首次配置滑条下键到上一步，再右键到完成。
- 设置内容最上方按上返回当前栏目，最后一个输入控件按下到保存；按钮、开关按方向键遵循屏幕排列。
- 确认弹窗可用方向键选择取消/确认，返回取消；管理员密码框默认获得焦点。诊断页可上下浏览，返回回到设置。
- 网页预览默认聚焦关闭；网页展示将焦点交给 WebView。展示页加载完成、收起系统输入法后输入 ↑ ↑ ↓ ↓ ← → ← → 确认 打开管理入口，有密码时仍需验证。
- 展示页返回键只返回网页历史，在首页不会退出展示。

网页内控件需要网页自身支持键盘焦点；应用不会注入脚本改写第三方网页。系统授权页、文件选择器和输入法采用电视系统自身的遥控交互。用户指定的大屏网址当前显示 Token 输入页，未取得 Token，尚未验证登录后的业务控件。
